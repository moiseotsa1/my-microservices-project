# 🔑 Configuration Token GitHub

## Créer un token GitHub:
1. Allez sur: https://github.com/settings/tokens
2. Cliquez "Generate new token"
3. Nom: "microservices-project"
4. Expiration: 90 jours
5. Permissions: Sélectionner "repo"
6. Générer le token
7. COPIER le token (il ne sera plus affiché)

## Utiliser le token:
Quand GitHub demande le mot de passe, utilisez le token au lieu de votre mot de passe.
